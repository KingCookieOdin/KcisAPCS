# 01 未登錄的編號

難度：基礎

## 題目說明

系統預期出現編號 1～n，但收到 n 筆登錄時可能有重複。列出尚未登錄的編號。

## 輸入格式

輸入若干整數直到輸入結束；整數總數就是 n。

## 輸出格式

由小到大列出缺少的編號，每個一行；全部出現時輸出 None。

## 資料範圍

1 ≤ n ≤ 1000；每個編號介於 1～n。

## 範例 1

### 輸入

```text
4 3 2 7 8 2 3 1
```

### 輸出

```text
5
6
```

## 範例 2

### 輸入

```text
1 2 3
```

### 輸出

```text
None
```

## 範例說明

8 筆登錄中沒有出現 5 與 6。
