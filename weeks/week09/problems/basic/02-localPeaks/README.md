# 02 量測序列的高點

難度：基礎

## 題目說明

感測器按時間記錄數值。若某筆紀錄嚴格大於前後兩筆，就標為局部高點；第一筆與最後一筆不列入。請統計並標示這些紀錄。

## 輸入格式

每組先輸入 n，再輸入 n 個整數；讀到輸入結束。

## 輸出格式

每組先輸出高點個數，再逐行輸出原數值，高點後緊接 +++++。兩組輸出間恰好空一行。

## 資料範圍

1 ≤ n ≤ 100；每筆數值 0～10000；最多 100 組。

## 範例

### 輸入

```text
5 120 130 120 130 140
```

### 輸出

```text
1
120
130+++++
120
130
140
```

## 範例說明

只有第二筆 130 同時大於左右紀錄。
