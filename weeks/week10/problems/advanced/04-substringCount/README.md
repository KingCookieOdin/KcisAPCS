# 04 文件片段搜尋

難度：進階

## 題目說明

搜尋工具要統計代碼中指定片段出現幾次。每個可能的起點都算一次，因此重疊的出現也要計算。大小寫視為不同。

## 輸入格式

第一個整數 n 表示查詢組數；接著每組輸入兩個不含空白的字串，依序為本文與搜尋片段。字串之間可用空白或換行分隔。

## 輸出格式

每組輸出一行出現次數。

## 資料範圍

1 ≤ n ≤ 100；本文長度 1～1000；片段長度 1～100；兩者只含英文字母與數字。

## 範例

### 輸入

```text
2
aaaa aa
thisisanapple anapple
```

### 輸出

```text
3
1
```

## 範例說明

aaaa 的第 1、2、3 個位置都可找到 aa；thisisanapple 中也有一次 anapple。
