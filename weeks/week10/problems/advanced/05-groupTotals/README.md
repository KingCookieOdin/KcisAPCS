# 05 分組紀錄加總

難度：進階

## 題目說明

每組測量紀錄包含不固定數量的整數。每組先給出資料筆數，再給出整數；請各自加總，不能把不同組混成同一筆。

## 輸入格式

第一個整數 n 表示組數。接著每組先輸入一個整數 k，再輸入 k 個整數。資料可分布在多行，組別由 k 決定，不依賴換行位置。

## 輸出格式

每組輸出一行整數總和；k 為 0 時輸出 0。

## 資料範圍

1 ≤ n ≤ 100；0 ≤ k ≤ 100；每個整數介於 −1000000～1000000。可用 `long long` 累計總和。

## 範例

### 輸入

```text
3
5 1 2 3 4 5
4 5 5 6 6
0
```

### 輸出

```text
15
22
0
```

## 範例說明

三組的總和依序是 15、22 與 0。
