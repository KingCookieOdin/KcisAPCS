# 03 圓形標籤讀值

難度：進階

## 題目說明

加工標籤混合字母與數字，唯一的大寫 R 後面是一段半徑數值。計算圓面積，使用 π = 3.14，並放入寬度 9 的顯示欄位；不足的左側位置以反斜線填滿。

## 輸入格式

一行不含空白的標籤；R 後是非負十進位數，至下一個英文字母或行尾結束。

## 輸出格式

輸出 |、9 字元的欄位、|。面積保留最多四位小數，刪除小數末端的 0；沒有小數時也刪除小數點。

## 資料範圍

標籤長度 1～100；半徑 0～100，最多一位小數；保證只有一個 R。

## 範例

### 輸入

```text
R12.5ABC
```

### 輸出

```text
|\\490.625|
```

## 範例說明

面積 490.625 共七個字元，左側補兩個反斜線。
