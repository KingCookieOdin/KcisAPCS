# 01 文字頻率摘要

難度：基礎

## 題目說明

文件索引需要知道一批單字中最常出現的英文字母。大小寫視為相同；若次數相同，取英文字母順序較前者。

## 輸入格式

第一個整數 n 表示單字數；接著輸入 n 個不含空白的單字。單字之間可用空白或換行分隔。

## 輸出格式

輸出大寫字母與次數，中間一個空格。

## 資料範圍

1 ≤ n ≤ 100；每個單字長度 1～100，只含英文字母。

## 範例

### 輸入

```text
5
A b a B c
```

### 輸出

```text
A 2
```

## 範例說明

A 與 B 各兩次，選擇字母序較前的 A。
