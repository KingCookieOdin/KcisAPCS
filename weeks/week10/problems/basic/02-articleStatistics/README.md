# 02 文章字母統計

難度：基礎

## 題目說明

文件管理系統收到一批不含空白的單字，要產生摘要：單字數，以及每個英文字母的出現次數。大小寫合併。

## 輸入格式

第一個整數 n 表示單字數；接著輸入 n 個不含空白的單字。單字之間可用空白或換行分隔。

## 輸出格式

先輸出單字數 n，再按 A～Z 順序列出有出現的字母與次數，每個字母占一行，字母與次數中間一個空格。

## 資料範圍

0 ≤ n ≤ 100；每個單字長度 1～100，只含英文字母。n 為 0 時只輸出 0。

## 範例

### 輸入

```text
3
Ab a C
```

### 輸出

```text
3
A 2
B 1
C 1
```

## 範例說明

三個單字中 A 出現兩次，B 與 C 各一次。
