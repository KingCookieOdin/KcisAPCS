# 03 設備異常連續紀錄

難度：進階

## 題目說明

監測系統按順序記錄多個場次的設備讀值。讀值**大於**該場次的警戒值才算異常；等於警戒值仍是正常。請統計每場的異常筆數，以及最長的連續異常筆數。正常讀值會讓目前的連續異常筆數歸零。

## 輸入格式

每個場次先輸入兩個整數 n、limit，表示讀值筆數與警戒值。接著輸入 n 個整數，依序表示讀值。

重複處理場次，直到讀到 `0 0` 為止。`0 0` 是結束標記，不屬於任何場次，也不輸出結果。

## 輸出格式

每個場次輸出一行兩個整數：異常筆數、最長連續異常筆數，以空格分隔。若沒有異常讀值，兩個數字都輸出 0。

## 資料範圍

每個場次滿足 1 ≤ n ≤ 100、0 ≤ limit ≤ 1000；每筆讀值介於 0～1000。最多 20 個場次。

## 範例

### 輸入

```text
6 70
72 75 68 71 90 70
4 50
50 51 52 53
0 0
```

### 輸出

```text
4 2
3 3
```

## 範例說明

第一場有四筆讀值大於 70，最長連續異常為兩筆（72、75 或 71、90）。第二場的 50 不算異常，後面三筆連續異常。
