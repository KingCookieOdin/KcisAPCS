# 02 入場票務統計

難度：基礎

## 題目說明

活動入口依年齡與會員身分計算票價。未滿 18 歲的基本票價為 80 元，18 歲以上為 120 元；會員在基本票價上再折 20 元。請依序處理每位入場者，統計未滿 18 歲的人數、會員人數與票價總收入。

## 輸入格式

第一行是一個整數 n，表示入場者人數。

接著有 n 筆資料，每筆包含一個整數 age 與一個字元 member，以空白分隔。`member` 為 `Y` 表示會員，`N` 表示非會員。資料可分布在多行，讀滿 n 筆即結束。

## 輸出格式

輸出一行三個整數，依序為未滿 18 歲的人數、會員人數、票價總收入，以空格分隔。

## 資料範圍

1 ≤ n ≤ 100；0 ≤ age ≤ 120；`member` 只會是大寫 `Y` 或 `N`。

## 範例

### 輸入

```text
4
16 Y
20 N
18 Y
12 N
```

### 輸出

```text
2 2 360
```

## 範例說明

兩位未滿 18 歲，兩位是會員。四張票的價格依序為 60、120、100、80 元，總收入為 360 元。
