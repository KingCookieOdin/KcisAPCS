# 03 超長金額加總

難度：進階

## 題目說明

封存資料以十進位文字保存非負整數，位數可能超過一般整數型態。請將兩筆數值相加，完整輸出結果。可從個位數開始相加，記錄進位，再將結果調整成正確順序。

## 輸入格式

第一個整數為組數 `t`，接著輸入 `t` 組資料；每組有兩個非負整數字串，以空白或換行分隔。

## 輸出格式

每組輸出一行總和，不保留前導零；若總和為零，輸出 `0`。

## 資料範圍

1 ≤ `t` ≤ 100；每個數字字串長度為 1～1000，只含數字，可含前導零。

## 範例

### 輸入

```text
3
9999999999999999999 1
00012 8
0 0
```

### 輸出

```text
10000000000000000000
20
0
```

## 範例說明

第一組產生最高位進位；第二組的前導零不影響數值。
