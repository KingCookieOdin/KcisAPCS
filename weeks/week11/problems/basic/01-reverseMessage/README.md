# 01 訊息順序還原

難度：基礎

## 題目說明

一批舊系統訊息在傳輸時，字元順序整段顛倒。每筆訊息都是不含空白的英數字代碼。請依原本順序輸出。

## 輸入格式

第一個整數為訊息筆數 `t`，接著輸入 `t` 個不含空白的代碼。

## 輸出格式

每筆訊息輸出一行還原後的代碼。大小寫與數字保持原樣。

## 資料範圍

1 ≤ `t` ≤ 100；每筆代碼長度為 1～1000，僅含英文字母與數字。

## 範例

### 輸入

```text
3
321CSPA
X
0aB
```

### 輸出

```text
APSC123
X
Ba0
```

## 範例說明

第一筆從最後一個字元開始，依序取到第一個字元。
