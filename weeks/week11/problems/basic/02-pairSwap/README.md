# 02 代碼相鄰交換

難度：基礎

## 題目說明

設備將代碼中的相鄰字元兩兩交換後存檔，例如 `ABCD` 會存成 `BADC`。請按相同規則處理輸入代碼，輸出交換後的結果。若長度為奇數，最後一個字元維持原位。

## 輸入格式

第一個整數為代碼筆數 `t`，接著輸入 `t` 個不含空白的代碼。

## 輸出格式

每筆代碼輸出一行交換後的結果。字元大小寫保持原樣。

## 資料範圍

1 ≤ `t` ≤ 100；每筆代碼長度為 1～1000，僅含英文字母與數字。

## 範例

### 輸入

```text
3
ABCD7
a1b2
Z
```

### 輸出

```text
BADC7
1a2b
Z
```

## 範例說明

`ABCD7` 的前四個字元分成 `AB`、`CD` 兩組交換，末尾的 `7` 保留。
