# Week 11：字串反向走訪與重建

## 今天的內容

沿用 `cin >>` 讀取不含空白的代碼，從尾端往前走訪字元，或每次處理兩個相鄰字元。把字元依新順序接成結果時，要留意長度為 1、奇數長度與索引邊界。進階題再用反向走訪處理十進位加法的進位；本週不要求函式拆解。

## 題目

課堂先完成 01，再選做 02；03 是進階挑戰，不要求三題全部完成。每題的 `main.cpp` 留空，請自行撰寫完整程式。

## 操作與測試

在 VS Code 開啟題目資料夾，閱讀 README 後完成程式。空白 main.cpp 尚不能編譯，要先寫出程式入口。修改後重新編譯，用範例核對結果，再試零、最小值或邊界情況；不要額外輸出「請輸入」等提示文字。

先用短代碼在紙上標出索引，再寫程式。完成後測試單一字元、奇數長度、進位與前導零。輸入中的空白和換行都只是欄位分隔。

下課前確認程式已儲存；要保留的進度請 commit 並 push 到自己的 GitHub repo。
